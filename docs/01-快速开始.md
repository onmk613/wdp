# 01 快速开始

## 构建

需要 Go 1.27+：

```sh
git clone <repo> wdp && cd wdp
./build.sh        # 缺省交叉编译全平台 → bin/wdp-<os>-<arch>[.exe] + SHA256SUMS
# 也可裸 go build（零 cgo 依赖；单产物，跨平台 push 需自行放置各平台二进制）
go build -o wdp ./cmd/wdp
```

产物是静态二进制，控制端与目标机都不需要任何运行时。`./build.sh` 产出的 bin 目录整体是控制端的分发单元：多平台二进制互为同级文件，push 自举与 agent 安装按目标机架构自动取同级对应文件，跨平台零配置。

本机演练用哪个平台的二进制都行，如同平台快捷方式：`ln -s $PWD/bin/wdp-$(go env GOOS)-$(go env GOARCH) /usr/local/bin/wdp`（同级查找会解析符号链接）。

## 第一个命令：本机演练

不需要任何远端主机。先写一个最小 inventory：

```sh
mkdir demo && cd demo
cat > inventory.yaml <<'YAML'
all:
  hosts:
    local: {conn: local}
YAML
```

临时执行一条命令（adhoc 模式）：

```sh
wdp adhoc -m shell -a 'uname -a' -i inventory.yaml local
```

输出类似：

```
TASK [adhoc (shell)] ********************
changed: [local]: done
```

提取字段进 shell 管道（`--format`，详见[输出控制](10-输出控制.md)）：

```sh
wdp adhoc -m shell -a 'hostname' --format '{{.stdout}}' -i inventory.yaml local
```

## 第一个 playbook

```yaml
# site.yaml
- name: 演示部署
  hosts: all
  tasks:
    - name: 创建目录
      file:
        path: /tmp/wdp-demo
        state: directory

    - name: 写入文件（内容变更才重写）
      copy:
        content: "hello wdp\n"
        dest: /tmp/wdp-demo/hello.txt

    - name: 验证
      shell: 'cat /tmp/wdp-demo/hello.txt'
```

先预演（不实际变更目标机），再执行：

```sh
wdp run site.yaml --check -i inventory.yaml   # check 模式：只报告将发生什么
wdp run site.yaml -i inventory.yaml           # 真实执行
```

重复执行第二次：`copy` 任务因校验和一致而不再变更——这就是 wdp 的幂等模型。

## 第一个应用包（chart）

复杂部署打包为自包含的 chart（参考 [examples/](../examples/) 的 node-exporter、docker 示例）。目录结构：

```
myapp/
├── chart.yaml      # 应用元数据（名称/版本/必填项）
├── values.yaml     # 默认配置（三层叠加的第 1 层）
├── deploy.yaml     # 部署任务编排
├── uninstall.yaml  # 卸载清单
├── status.yaml     # 状态探测
├── _helpers.tpl    # 命名模板
├── templates/      # 配置文件模板
└── envs/           # 环境覆盖（prod/staging）
```

完整的开发-预演-发布循环：

```sh
wdp lint ./myapp                                  # 结构校验
wdp render ./myapp -f envs/prod.yaml                     # 预览渲染结果
wdp run ./myapp --check --diff -i inventory.yaml -f envs/prod.yaml  # 零风险预演+内容差异
wdp run ./myapp -i inventory.yaml -f envs/prod.yaml                # 部署
wdp run ./myapp --phase status -i inventory.yaml                    # 查状态
wdp run ./myapp --phase uninstall -i inventory.yaml                 # 卸载
```
