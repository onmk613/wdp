# 10 输出控制

## 详细级别：-v 可重复、-q 静默

| 级别 | 效果 |
|---|---|
| 缺省 | 聚合模式（面向大规模主机）：每任务仅以表格呈现 failed/unreachable 主机（含 loop 异常项、diff 预演）+ 一行汇总（`» N 台: ok=x changed=x …`） |
| `-q` / `--quiet` | 仅异常主机行 + RECAP，行式输出（脚本/管道友好，不做表格；警告/错误类消息保留） |
| `-v` | 逐主机全量表格（ok/skipped/changed 都显示） |
| `-vv` | 表格 + 逐主机详情块：完整 stdout/stderr（不截断）+ loop 逐项结果（含 item 标签） |
| `-vvv` | 调试：失败与否 stderr 恒显示 |

```sh
wdp run site.yaml -i inv.yaml          # 聚合
wdp run site.yaml -i inv.yaml -v       # 逐主机
wdp run site.yaml -i inv.yaml -vv      # 全量输出 + loop 逐项
```

`wdp.cfg [run] verbose = true` 等价 `-v`。

## 表格化输出

任务结果与 PLAY RECAP 以表格呈现（`HOST / STATUS / DETAIL` 与
`OK / CHANGED / FAILED / …` 数字列右对齐、中文按双列宽对齐）：

```text
TASK [失败示例 (shell)] ********************
HOST  STATUS  DETAIL
----  ------  ---------------
web2  fatal   非零退出码 rc=3
web1  fatal   非零退出码 rc=3

PLAY RECAP [演示] ********************
HOST  OK  CHANGED  FAILED  UNREACHABLE  SKIPPED  IGNORED
----  --  -------  ------  -----------  -------  -------
db1    0        2       0            0        0        1
```

- 多行内容（diff、stderr、全量 stdout、loop 逐项）不放单元格：摘要取首行，
  全量内容在表格下方按主机分组缩进输出（`  主机:` 引导）
- 单任务超 1000 行结果自动降级为 TSV 流式输出（制表符分隔，`column -t -s$'\t'` 可还原对齐）

其它聚合行为：RECAP 超 100 台主机折叠为 TOTAL 行；单任务输出超 1MB 自动截断（防 cat 大文件撑爆内存）。

## 任务级展示控制：output / no_log

任务属性 `output` **只控回显、不控数据**——register 始终拿到完整 stdout：

```yaml
- name: 噪音很大的构建
  shell: './build.sh'
  output: tail=30          # 只显示最后 30 行

- name: 敏感输出任务
  shell: './rotate-keys.sh'
  no_log: true             # 等价 output=none，stdout/stderr/msg 不回显

- name: 只看一行摘要
  shell: './report.sh'
  output: oneline
```

| 值 | 效果 |
|---|---|
| `full` | 原文（任何级别下不截断） |
| `none` | 不回显（register 数据不受影响） |
| `oneline` | 仅首行 |
| `head=N` | 前 N 行 |
| `tail=N` | 后 N 行 |

`no_log: true` 等价 `output: none`（语义别名，兼容习惯写法）。

`no_log` 与 `output: none` 的区别在数据面：`output` 只控回显（JSON 报告仍含完整数据），
而 **`no_log` 任务在 `--output json` 报告中遮蔽为 `"<redacted>"`**（stdout/stderr/msg/diff
含 loop 逐项）——JSON 报告常落 CI 工件，敏感输出不得随报告持久化；register 变量在内存中不受影响。

## loop 逐项展示

- 缺省聚合模式：仅异常项可见（表格内 `item=x …` 独立行）
- `-vv`：全部项在主机详情块中逐行显示（`item=a ok: …`）
- `--output json`：`items` 数组含每项完整结果

## adhoc --format：进 shell 管道

逐主机一行模板化输出（可用字段：`.host .stdout .stderr .rc .changed .failed .skipped .unreachable .msg .elapsed_ms`）：

```sh
wdp adhoc -m shell -a 'uptime' --format '{{.host}}: {{.stdout}}' -i inv.yaml all

# 组合进管道
wdp adhoc -m shell -a 'df -B1 /' --format '{{.host}} {{.stdout}}' -i inv.yaml all \
  | awk '{print $1, $6}' | sort -k2 -n

# 退出码语义保持：有主机失败则 wdp 返回非零
```

## JSON 输出：--output json

```sh
wdp run site.yaml -i inv.yaml --output json > result.json
```

- stdout 仅输出最终完整文档（plays → tasks → 逐主机结果 + loop items + diff + RECAP），进度信息不打印
- `no_log: true` 任务的结果遮蔽为 `"<redacted>"`（见上）
- snake_case 字段，适配 CI/CD 解析（门禁、通知、审计）
- 与 `--check` 组合可做"预演结果机器评审"

## 颜色

TTY 自动着色；`--no-color` 或 wdp.cfg `[output] color = false` 关闭。diff 的 `+`/`-` 行始终红绿区分（详见[预演文档](11-check与diff预演.md)）。
