# wdp 用户文档

wdp 是 Go 编写的自动化部署工具：单二进制、零运行时依赖，支持常驻 agent（默认，mTLS）/ local 两种通道，Helm 风格 chart 应用包 + 声明式任务编排。（web-console 分支正向 Web 管理端演进，main 分支仍为三通道形态）
