# wdp 用户文档

wdp 是 Go 编写的自动化部署工具：单二进制、零运行时依赖，支持 SSH / 常驻 agent / push 临时 agent 三种通道，Helm 风格 chart 应用包 + 声明式任务编排。

| 文档 | 内容 |

| [02-配置文件](02-配置文件.md) | wdp.cfg 全量配置项、优先级、敏感信息处理 |
| [03-Inventory 主机清单](03-inventory主机清单.md) | 主机/分组/变量、选择模式（通配/交集/排除）、多文件合并、group_vars/host_vars |
| [04-连接与认证](04-连接与认证.md) | ssh/agent/push/local 四种通道、密钥与密码、mTLS 自建 CA、主机指纹 |
| [05-Playbook 任务编排](05-playbook任务编排.md) | play/task 全部控制属性、条件、循环、block 容错、委托、hook、内置变量 |
| [06-部署策略与自动回滚](06-部署策略与自动回滚.md) | 金丝雀/滚动分批、健康门、自动回滚的覆盖范围与限制 |

> 模块参数文档也可直接用 `wdp modules <模块名>` 查看（与实现同源，永不漂移）。
