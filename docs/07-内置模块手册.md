# 07 内置模块手册

19 个内置模块 + chart 脚本模块机制。通用约定：

- **模块键**是任务 YAML 里唯一的非控制属性键：`shell: 'uptime'`（简写 free-form）或 map 形式参数
- 所有模块在控制端实现，SSH / agent / push / local 通道行为一致
- **幂等**是默认设计目标：探测后变更，重复执行收敛到"无变化"
- `--check` 模式返回真实变更预估（探测只读，不做任何变更）；`--diff` 追加内容级差异
- 文件类模块（copy/template/file/unarchive 及其复用者）接入 `auto_rollback` 变更日志
- 随时用 `wdp modules <模块名>` 查看与实现同源的参数文档

---

## shell / command

远端执行命令。`shell` 与 `command` 行为一致（都经 /bin/sh）。

```yaml
- name: 查看 uptime
  shell: 'uptime'

- name: 幂等执行（产物存在则跳过；简写参数不能与 args 同用，改用 map 形式）
  command:
    cmd: ./migrate.sh
    creates: /opt/app/.migrated

- name: 前置目录与守卫
  shell:
    cmd: ./build.sh
    chdir: /opt/app
    creates: /opt/app/.built
```

| 参数 | 说明 |
|---|---|
| （free-form） | 命令本体 |
| `cmd` | free-form 为空时的替代写法 |
| `creates` | 路径存在则跳过（幂等守卫） |
| `removes` | 路径不存在则跳过（幂等守卫） |
| `chdir` | 执行前 cd 到该目录 |

- 幂等仅靠 `creates`/`removes` 守卫；无守卫时每次执行都记 changed
- 非零退出码判失败（`rc` 进入 register，可用 `failed_when` 覆盖）
- check 模式：返回"将执行"预估（有 creates/removes 守卫时按守卫判断是否跳过）

## script

上传本地脚本到远端临时路径执行，结束自删。

```yaml
- name: 迁移脚本
  script: scripts/migrate.sh --verbose
```

| 参数 | 说明 |
|---|---|
| `src` | 本地脚本路径（playbook/chart 相对路径） |
| （free-form） | 传给脚本的参数 |

- 不幂等（每次执行记 changed）；check 模式返回"将执行"预估，不上传不执行
- 脚本上传按 0755，目标机需有对应解释器（shebang 决定）
- 参数按 POSIX sh 词法切词后逐词单引号转义再拼接：参数中的 `$`、`;`、`&&`、
  反引号等元字符一律字面传给脚本，不经远端 shell 二次解释（含未闭合引号的
  参数串直接报错）；需要 shell 展开时在脚本内部自行 `eval`

## copy

分发本地文件或字面量内容到远端（sha256 校验和幂等）。

```yaml
- name: 下发静态配置
  copy:
    src: files/app.conf            # 本地文件
    dest: /etc/app/app.conf
    mode: "0644"
    owner: app                     # 需 become
    group: app
    backup: true                   # 覆盖前备份为 dest.bak.<时间戳>

- name: 字面量内容
  copy:
    content: "127.0.0.1 localhost\n"
    dest: /etc/app/hosts.txt
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `dest` | 必需 | 远端目标路径 |
| `content` / `src` | 二选一 | 字面量内容 / 本地源文件 |
| `mode` | 0644（src 时沿用本地权限） | 权限（八进制字符串如 "0755"；仅权限位 0..0777，setuid 等特殊位会被拒绝，需要时用 shell chmod） |
| `owner` / `group` | - | 属主/属组，**需要 become**（否则显式报错） |
| `backup` | false | 覆盖前备份 |

- 内容一致时仍校正权限/属主漂移（修正记 changed）
- check 模式：校验和 + 权限对比预估；`--diff` 输出 unified diff
- 回滚：覆盖前快照恢复 / 新建删除

## template

本地渲染 Go 模板后分发（幂等机制同 copy；chart 场景可用 `_helpers.tpl` 命名模板与全部模板函数）。

```yaml
- name: 渲染 nginx 配置
  template:
    src: templates/nginx.conf.tpl
    dest: /etc/nginx/nginx.conf
    mode: "0644"
  notify: 重载 nginx
```

| 参数 | 说明 |
|---|---|
| `src` | 本地模板路径（必需） |
| `dest` | 远端目标路径（必需） |
| `mode` / `owner` / `group` / `backup` | 同 copy |

模板函数与命名模板见 [09-Values 与模板函数](09-values与模板函数.md)。

## fetch

拉取远端文件到本地。

```yaml
- name: 收集错误日志
  fetch:
    src: /var/log/app/error.log
    dest: ./logs           # 层级模式：logs/<主机名>/var/log/app/error.log
    flat: false
```

| 参数 | 说明 |
|---|---|
| `src` | 远端源文件路径（必需） |
| `dest` | 本地目标目录（必需） |
| `flat` | false（默认）：`dest/<主机名>/<原路径去首斜杠>`；true：拍平为 `dest/<文件名>` |

幂等：本地已存在同校验和文件则跳过下载。远端文件不存在判失败。只读模块，check 模式行为不变。

## file

管理远端文件/目录/链接的状态与属性。

```yaml
- name: 目录
  file:
    path: /opt/myapp
    state: directory
    mode: "0755"

- name: 版本软链
  file:
    src: /opt/myapp/releases/v1.2.3    # 链接目标（state=link 时必需）
    dest: /opt/myapp/current
    state: link

- name: 删除
  file:
    path: /tmp/legacy
    state: absent

- name: 仅校正属性（不创建）
  file:
    path: /etc/app/app.conf
    owner: app
    group: app
```

| 参数 | 说明 |
|---|---|
| `path` | 远端路径（必需） |
| `state` | `file`（不创建，缺文件报错）/ `directory` / `link` / `touch` / `absent` |
| `mode` | 权限，如 "0755" |
| `owner` / `group` | 需 become |
| `src` | state=link 的链接目标 |

- 类型冲突显式报错（如 path 已存在且非目录时 state=directory）
- check 模式：状态/权限/属主/链接目标漂移全量预估；`--diff` 输出属性 before→after
- 回滚：新建删除 / 变更快照恢复

## package

跨发行版包管理（读 /etc/os-release 自动识别 apt / dnf / yum / apk / zypper）。

```yaml
- name: 安装依赖
  package:
    name: [curl, jq]           # 字符串（空白分割）或列表
    state: present             # present（默认）| latest | absent
```

| 参数 | 说明 |
|---|---|
| `name` | 包名（必需，字符串或列表） |
| `state` | present / latest / absent |

- 幂等：逐包探测已装状态（dpkg-query / rpm -q / apk info）
- `latest` 幂等：先探测可用升级（apt 模拟升级汇总行 / dnf·yum check-update / apk version -l '<' / zypper list-updates），无升级即跳过且不报 changed
- check 模式：逐包"将安装/将卸载/将升级/已是最新"；`--diff` 输出逐包 `+`/`-`/`~` 行
- 系统级变更不登记回滚（逆操作写入 uninstall.yaml）

## service

systemd 服务状态与自启管理（仅 systemd，V1）。

```yaml
- name: 启动并自启
  service:
    name: nginx
    state: started        # started | stopped | restarted | reloaded
    enabled: true
```

| 参数 | 说明 |
|---|---|
| `name` | 单元名（必需） |
| `state` | started / stopped / restarted / reloaded |
| `enabled` | 开机自启 |

- `state` 与 `enabled` 至少一项
- 幂等：is-active / is-enabled 探测，仅状态漂移才动作；`reloaded` 对未运行服务等价 start
- check 模式：状态预估；`--diff` 输出 `active/inactive`、`enabled/disabled` 前后对照

## setup

采集主机 facts 并入变量域（无参数，只读）。

```yaml
- name: 采集 facts
  setup: {}

- name: 引用
  shell: 'echo {{ .os.family }} {{ .cpus }}C {{ .memory_mb }}MB disk {{ .disk.use_percent }}%'
```

采集内容：

| 变量 | 内容 |
|---|---|
| `hostname` / `kernel` / `arch` | 主机名 / 内核版本 / 架构 |
| `default_ipv4` | 默认出口 IPv4 |
| `euid` | 有效用户 id（系统级任务 root 守卫依据；采集失败按 -1 非根处理） |
| `os.id` / `os.name` / `os.version` / `os.family` | 系统标识（family: debian/redhat/alpine/suse/unknown） |
| `cpus` | CPU 数 |
| `memory_mb` | 内存 MB |
| `disk.total_bytes` / `used_bytes` / `avail_bytes` / `use_percent` | 根分区磁盘 |

facts 跨批次、跨 play、跨子 chart 作用域延续；配合 `group_by` 做动态分组。

## user / group

系统用户/组管理（漂移探测式幂等，变更需 become）。

```yaml
- name: 创建应用用户
  user:
    name: myapp
    group: myapp              # 主组
    groups: [docker]          # 附加组（集合比较，收敛不抖动）
    shell: /usr/sbin/nologin
    home: /opt/myapp
    system: true
  become: true

- name: 校正漂移（仅 uid/shell 等变化才 usermod）
  user: {name: deploy, shell: /bin/bash}
  become: true

- name: 删除用户（含 home，不可回滚）
  user: {name: leaver, state: absent}
  become: true

- name: 组管理
  group: {name: myapp, gid: 1500, system: true}
  become: true
```

**user 参数**：`name`（必需）、`state: present|absent`、`uid`、`group`（主组）、`groups`（列表）、`append`（true 时 groups 只增不删，走 `usermod -aG`；false 缺省整体覆盖）、`shell`、`home`、`system`、`password`（crypt 哈希，仅创建时生效）。

> ⚠️ `groups` 缺省语义为**整体覆盖**：未列出的既有附加组（如 wheel/sudo）会被移除。
> 需要"确保成员、不删其它组"时显式 `append: true`。

**group 参数**：`name`（必需）、`state: present|absent`、`gid`、`system`。

- 已存在用户仅校正漂移属性（uid/主组/附加组/shell/home），无漂移不执行 usermod
- check 模式：逐属性漂移预估；`--diff` 输出属性 before→after
- 系统级变更不登记回滚（不可逆，评估报告会提示）

## systemd_unit

部署 systemd 单元文件 + daemon-reload + 状态管理（文件部分复用 copy 的幂等/备份/回滚管线）。

```yaml
- name: 部署 myapp 服务
  systemd_unit:
    name: myapp.service
    content: |
      [Unit]
      Description=MyApp

      [Service]
      ExecStart=/opt/myapp/bin/myapp

      [Install]
      WantedBy=multi-user.target
    state: started
    enabled: true
  become: true
  # 文件内容变更时自动 daemon-reload，无需额外 handler

- name: 模板渲染部署（src 含 {{ }} 自动渲染）
  systemd_unit:
    name: worker.service
    src: templates/worker.service.tpl
    state: restarted
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `name` | 必需 | 单元文件名（basename，如 myapp.service） |
| `content` / `src` | 二选一 | 字面量内容 / 本地模板路径（含 `{{` 时渲染） |
| `dest_dir` | /etc/systemd/system | 单元部署目录 |
| `state` | - | started / stopped / restarted / reloaded |
| `enabled` | - | 开机自启 |
| `daemon_reload` | true | 文件变更后 systemctl daemon-reload |

## unarchive

解压 tar(.gz/.xz)/zip 归档到远端目录。

解压双路径：agent/push 通道由 agent 侧 Go 原生解压（不依赖目标机的
tar/unzip/xz 工具，归档条目做路径逃逸防护）；SSH 通道与旧版常驻 agent
自动回退 shell 命令（此时目标机需有对应工具）。

```yaml
- name: 部署应用包
  unarchive:
    src: files/myapp-1.2.3.tar.gz    # 本地归档（相对 playbook/chart）
    dest: /opt/myapp
    creates: /opt/myapp/bin/myapp     # 幂等守卫：该路径存在则跳过

- name: 远端已有归档直接解压
  unarchive:
    src: /tmp/data.zip
    dest: /srv/data
    remote_src: true
```

| 参数 | 说明 |
|---|---|
| `src` | 归档路径（必需） |
| `dest` | 远端目标目录（必需，自动创建） |
| `remote_src` | src 为远端路径（跳过上传） |
| `creates` | 幂等守卫路径（控制端看不到归档内容，重复执行依赖此项） |
| `remove` | 已废弃（保留兼容）：上传的临时归档副本现在总是自动清理（成败路径均清理） |

- 支持格式：`.tar` / `.tgz` / `.tar.gz` / `.txz` / `.tar.xz` / `.zip`（zip 需目标机有 unzip）
- 回滚：目标目录为新建时登记删除
- check 模式：报告将解压；`--diff` 显示目标目录状态变化

## get_url

下载 URL 到远端文件（控制端下载 + 校验，再走 copy 幂等管线）。

```yaml
- name: 下载制品（sha256 校验与幂等）
  get_url:
    url: https://repo.example.com/myapp-1.2.3.bin
    dest: /opt/myapp/artifact.bin
    sha256: "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855"
    mode: "0755"
    headers:
      Authorization: "Bearer {{ .artifact_token }}"
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `url` | 必需 | 下载地址 |
| `dest` | 必需 | 远端目标路径 |
| `sha256` | - | 校验和（同时是幂等依据：远端已是该值则跳过下载） |
| `mode` | 0644 | 权限 |
| `owner` / `group` | - | 需 become |
| `timeout_secs` | 30 | 下载超时 |
| `headers` | - | 请求头 map |

- 校验和不匹配判失败；非 200 判失败
- 响应体上限 2GiB（Content-Length 预检 + 流式截断，防异常 URL 撑爆控制端内存）；
  可经 `--max-download-mb` 或 wdp.cfg `[transfer].max_download_mb` 调整
- `--diff` 输出远端内容与下载内容的 unified diff

## lineinfile

远端文件的单行管理。

```yaml
- name: 确保行存在（精确行已存在则不动）
  lineinfile:
    path: /etc/sysctl.d/99-app.conf
    line: "vm.swappiness = 10"
    create: true

- name: 替换首个匹配行
  lineinfile:
    path: /etc/app/app.conf
    regexp: '^worker_processes .*'
    line: "worker_processes = 8"

- name: 删除全部匹配行
  lineinfile:
    path: /etc/hosts
    regexp: '^10\.0\.0\.\d+ legacy'
    state: absent

- name: 插入到指定行之后
  lineinfile:
    path: /etc/app/app.conf
    line: "# managed"
    insertafter: '^\[main\]'
```

| 参数 | 说明 |
|---|---|
| `path` | 远端文件（必需） |
| `line` | 目标行（present 时必需） |
| `regexp` | 匹配正则（present：替换首个匹配；absent：删除全部匹配） |
| `state` | present（默认）/ absent |
| `insertafter` | 无匹配时的插入锚点（正则，默认 EOF） |
| `create` | 文件不存在时创建（默认 false 报错） |
| `backup` | 覆盖前备份 |
| `mode` / `owner` / `group` | 创建时生效 |

- check 模式：行级变更预估；`--diff` 输出行级 unified diff
- 回滚：整文件快照恢复

## wait_for

等待条件满足（**控制端视角**轮询：端口探测从控制端发起）。

```yaml
- name: 等待数据库端口就绪
  wait_for:
    host: "{{ (index .hosts 'db1').address }}"
    port: 5432
    timeout: 60

- name: 等待远端文件出现
  wait_for:
    path: /opt/myapp/.ready
    timeout: 30
    sleep: 2
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `host` | 目标主机地址 | 探测地址 |
| `port` | - | TCP 端口（可达即满足） |
| `path` | - | 远端文件路径（存在即满足；state=absent 反之） |
| `state` | present | present / absent（对端口：关闭才算满足） |
| `timeout` | 300 | 总超时秒 |
| `delay` | 0 | 首次探测前等待 |
| `sleep` | 1 | 探测间隔秒 |
| `msg` | - | 自定义超时消息 |

- 条件满足记 ok（不记 changed）；超时判失败
- check 模式：单次探测报告就绪状态，不等待
- 注意：端口探测是控制端视角；需要目标机本机视角时用 `shell + until`

## stat

远端文件元数据采集 → facts 变量（只读，不记 changed）。

```yaml
- name: 探测配置文件
  stat:
    path: /etc/nginx/nginx.conf
    get_checksum: true        # 默认 true（文件 <1MB 时）

- name: 条件引用（结果在 .stat.*，同 setup 语义）
  service:
    name: nginx
    state: restarted
  when: '{{ .stat.exists }}'

- name: 变量引用
  shell: 'echo {{ .stat.size }} bytes, mode {{ .stat.mode }}'
```

| 参数 | 说明 |
|---|---|
| `path` | 远端路径（必需） |
| `get_checksum` | 采集 sha256（默认 true，限 <1MB 普通文件） |
| `follow` | 跟随符号链接（islink 仍为 true，属性取目标） |

采集的 `.stat.*` 键：`exists` / `isdir` / `islink` / `isfile` / `mode`（"0644" 八进制字符串）/ `size`（字节）/ `owner` / `group` / `checksum` / `path`。

## chart 脚本模块（扩展机制）

内置注册表未命中时，按目录约定发现 chart 自带模块——**应用包无需改 wdp 源码即可扩展**：

```
mychart/
└── modules/
    └── my-check            # 任意可执行脚本（目标机需有解释器，按 shebang）
```

```yaml
- name: 自检
  my-check:
    timeout: 5              # 参数以 JSON 对象注入
```

契约：

| 环境变量 | 内容 |
|---|---|
| `WDP_MODULE_ARGS` | 任务参数（JSON 对象字符串） |
| `WDP_FREE_FORM` | 简写参数原文 |
| `WDP_CHECK` | check 模式时为 `1`（脚本应只读探测并返回预估） |

结果判定：stdout 为 JSON 对象 `{"changed":..,"failed":..,"msg":".."}` 时按声明判定；否则 rc==0 即 changed（stdout 原文作为 msg）。

示例脚本：

```sh
#!/bin/sh
# 解析参数（无 jq 时用 sed 提取，或用 python -c）
timeout=$(echo "$WDP_MODULE_ARGS" | sed -n 's/.*"timeout":\([0-9]*\).*/\1/p')
[ -n "$timeout" ] || timeout=5

if [ "$WDP_CHECK" = "1" ]; then
  echo '{"changed": false, "failed": false, "msg": "[check] 将自检"}'
  exit 0
fi
if do-selfcheck; then
  echo '{"changed": true, "failed": false, "msg": "自检通过"}'
else
  echo '{"changed": false, "failed": true, "msg": "自检失败"}'
fi
```

lint 与 `wdp template` 会识别 `modules/` 目录中的模块名，脚本模块可直接通过校验。
