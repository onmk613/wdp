# 02 配置文件 wdp.cfg

TOML 格式。默认读取**当前工作目录**的 `wdp.cfg`（不存在则静默跳过，全部用内置默认值）；`--config <路径>` 显式指定时文件必须存在（否则报错）。

## 优先级

```
CLI flag 显式值  >  wdp.cfg  >  内置默认
```

即：命令行上出现过的 flag 永远生效；未出现时回退配置文件；两者都没有用内置默认。

## 全量配置项

```toml
[inventory]
path = "inventory.yaml"      # -i 的默认值

[run]
forks = 5                    # 并发主机数（-v 看明细时建议调大）
timeout = 0                  # 全局墙钟超时（秒），0 不限
task_timeout = 0             # 任务默认超时（秒），0 不限；任务级 timeout 属性可覆盖
verbose = false              # true 等价于 -v（逐主机输出）
conn = ""                    # 默认连接类型（空 = push；可选 ssh/agent/local，fleet 级默认；优先级见 docs/04）

[output]
color = true                 # 颜色输出（--no-color 关闭）

[ssh]                        # inventory 与 ~/.ssh/config 均未显式指定时的连接默认值
                             #   （优先级：主机条目 > 组 vars > ~/.ssh/config > 此处，见 docs/04）
user = "root"
connect_timeout = 10         # 建连超时秒
host_key_check = true        # 校验主机指纹（安全默认；见下）
known_hosts = ""             # 空 = ~/.ssh/known_hosts

[agent]
port = 7602                  # agent/push 通道默认端口（wdp agent 未显式 --listen 时绑定 127.0.0.1:该端口）
cert_rotate_min = 0          # push 临时证书轮换周期分钟（0 = 不轮换；如 30 = 每 30 分钟换一代信任链，
                             #   压缩共享证书对的暴露窗口，仅对仍有后续任务的主机生效）
idle_timeout_min = 60        # push 临时 agent 空闲自动退出分钟（0 = 默认 60；<0（如 -1）= 禁用）。
                             #   控制端崩溃/被杀/断网时 Close 不会被调用，远端 agent 超过该周期无已认证
                             #   请求即自删退出（--cleanup-on-shutdown）；/health 免认证探测不计入活动，
                             #   同网段无法给残留 agent 续命。常驻 agent 不受影响（其 --idle-timeout 需显式指定）

[agent.push_binary]          # push 自举按目标平台的二进制表（跨平台控制端用，如 macOS 控制 Linux）
                             #   自举前经 uname -sm 探测目标平台，命中此表用对应二进制；目标与控制端
                             #   同平台时无需配置（直接上传自身）；跨平台且未配置时自动回退纯 SSH 并提示
# linux_amd64 = "/path/bin/wdp-linux-amd64"   # ./build.sh linux/amd64 产物
# linux_arm64 = "/path/bin/wdp-linux-arm64"

[transfer]                   # 文件传输上限（CLI 显式值优先：--max-download-mb）
max_download_mb = 2048       # get_url 下载响应体上限 MiB（0 = 内置默认 2048）
max_extract_mb = 2048        # chart tgz 解包总量上限 MiB（0 = 内置默认 2048）
```

## 示例：团队统一默认

```toml
[inventory]
path = "inventories/prod.yaml"

[run]
forks = 20
task_timeout = 300

[ssh]
user = "deploy"
host_key_check = true
```

## 敏感信息不入库的三种写法

任何敏感字段都支持**环境变量引用**，配置文件与 inventory 里只留引用：

| 写法 | 说明 |
|---|---|
| `password_env: SSH_PW` | 独立 `*_env` 键指定环境变量名 |
| `password: "env:SSH_PW"` | 值内 `env:` 前缀引用 |
| `become_password_env: SUDO_PW` | sudo 密码等敏感值同理（所有 `*_env` 键） |

```sh
export SSH_PW='...'
wdp run site.yaml -i prod.yaml   # SSH 密码从环境读取
```

## 与 CLI 的对应关系

| 配置项 | 等价 flag |
|---|---|
| `inventory.path` | `--inventory / -i` |
| `run.forks` | `--forks` |
| `run.timeout` | `--timeout` |
| `run.task_timeout` | `--task-timeout` |
| `run.verbose` | `-v`（计数级别的第一档） |
| `output.color = false` | `--no-color` |
