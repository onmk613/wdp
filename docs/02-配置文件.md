# 02 配置文件 wdp.cfg

TOML 格式。默认读取**当前工作目录**的 `wdp.cfg`（不存在则静默跳过，全部用内置默认值）；`--config <路径>` 显式指定时文件必须存在（否则报错）。

## 优先级

```
CLI flag 显式值  >  wdp.cfg  >  内置默认
```

即：命令行上出现过的 flag 永远生效；未出现时回退配置文件；两者都没有用内置默认。

## 全量配置项

```toml
[inventory]
path = "inventory.yaml"      # -i 的默认值

[run]
forks = 5                    # 并发主机数（-v 看明细时建议调大）
timeout = 0                  # 全局墙钟超时（秒），0 不限
task_timeout = 0             # 任务默认超时（秒），0 不限；任务级 timeout 属性可覆盖
verbose = false              # true 等价于 -v（逐主机输出）
conn = ""                    # 默认连接类型（空 = agent；可选 agent/local，fleet 级默认；优先级见 docs/04）

[output]
color = true                 # 颜色输出（--no-color 关闭）

[agent]
port = 7602                  # agent 通道默认端口（wdp agent 未显式 --listen 时绑定 127.0.0.1:该端口）

[transfer]                   # 文件传输上限（CLI 显式值优先：--max-download-mb）
max_download_mb = 2048       # get_url 下载响应体上限 MiB（0 = 内置默认 2048）
max_extract_mb = 2048        # chart tgz 解包总量上限 MiB（0 = 内置默认 2048）
```

## 示例：团队统一默认

```toml
[inventory]
path = "inventories/prod.yaml"

[run]
forks = 20
task_timeout = 300
```

## 敏感信息不入库的两种写法

敏感字段支持**环境变量引用**，配置文件与 inventory 里只留引用：

| 写法 | 说明 |
|---|---|
| `become_password_env: SUDO_PW` | 独立 `*_env` 键指定环境变量名 |
| `become_password: "env:SUDO_PW"` | 值内 `env:` 前缀引用 |

```sh
export SUDO_PW='...'
wdp run site.yaml -i prod.yaml   # sudo 密码从环境读取
```

## 与 CLI 的对应关系

| 配置项 | 等价 flag |
|---|---|
| `inventory.path` | `--inventory / -i` |
| `run.forks` | `--forks` |
| `run.timeout` | `--timeout` |
| `run.task_timeout` | `--task-timeout` |
| `run.verbose` | `-v`（计数级别的第一档） |
| `output.color = false` | `--no-color` |
