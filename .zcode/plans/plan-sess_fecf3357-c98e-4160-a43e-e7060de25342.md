# wdp V2：cobra CLI + 认证体系 + 临时 agent + 性能与 chart 增强

## Phase 1：CLI 迁移 spf13/cobra
- `cmd/wdp/main.go` 简化为 `cli.Execute()`；`internal/cli/` 改造：`root.go`（PersistentFlags：`--inventory/-i`、`--forks`、`--timeout`、`--task-timeout`、`--verbose`、`--no-color`）+ run/adhoc/agent/template/lint/package/ca/release/modules 子命令
- 现有 flag 语义不变（`-f` values、`--set`、`--limit` 等），删除自实现 parseFlags/multiFlag（cobra+pflag 原生支持重复与交错 flag）
- 新增依赖：spf13/cobra、spf13/pflag（纯 Go）

## Phase 2：超时体系 + 1000 主机性能
**三级超时**：
- 连接级：host 键 `connect_timeout`（默认 10s，SSH dial 与 agent 健康检查）
- 任务级：task 属性 `timeout: 300`（秒）+ 全局 `--task-timeout` 默认 300s；executor 将其写入 `ExecRequest.TimeoutMs`（**打通现有未接通链路**，SSH 层 ctx 关 session、agent 层 kill 进程）
- 全局级：`--timeout` 包裹整个 run 的 wall-clock

**性能改造**：
- `connection.Manager`：并发建连信号量（`2×forks`），防 1000 主机瞬时 SSH 握手洪峰；连接失败快速返回（unreachable 不重试拖垮任务）
- 聚合输出模式（默认）：每任务只逐行打印 failed/unreachable，任务结束打一行 `TASK [x] ok=800 changed=150 failed=5 skipped=45 (1000)`；`--verbose` 切回逐主机全量
- 输出截断：模块 ExecResult stdout/stderr 超 1MB 截断并标注（防 `cat 大文件` 内存爆）
- 压测：`scripts/gen-inventory.sh`（生成 N×local 主机）+ `examples/bench/`，验收 1000 主机 × shell+copy 任务调度稳定

## Phase 3：SSH 认证补全 + sudo 密码提权
- 认证链（顺序可配）：私钥（显式 `key_path`，支持 `key_passphrase`/`key_passphrase_env` 口令）→ ssh-agent（SSH_AUTH_SOCK 自动）→ 默认密钥 → `password`/`password_env`（环境变量引用，避免 inventory 明文）→ keyboard-interactive（有密码时启用）
- 主机指纹：`host_key_check: true` + `known_hosts`（默认 ~/.ssh/known_hosts，x/crypto/ssh/knownhosts）
- sudo 密码：host 键 `become_password`/`become_password_env`；SSH 路径先 `sudo -S -p '' -v` 缓存凭证再执行（每 Exec 多一次往返，可接受）；agent 路径 `/exec` 增加 `become_user`/`become_password` 字段

## Phase 4：Agent 认证（token + mTLS 双模式）+ CA 工具链
- agent 启动：`--token <secret>`（header `X-WDP-Token` 常量时间比较）或 `--ca/--cert/--key`（mTLS：`ClientAuth: RequireAndVerifyClientCert`，ListenAndServeTLS）
- 控制端 inventory host 键：`token`/`token_env`；`ca_file`+`cert_file`+`key_file`（https + ServerName）
- `wdp ca init [--dir]`：生成 CA（10 年）；`wdp ca issue --name <n> [--client]`：签发服务端/客户端证书（internal/ca，crypto/x509 标准库）

## Phase 5：临时 agent 自举（真端口开放，非隧道）
- 新连接类型 `conn: push`，流程：
  1. **SSH 自举**（短暂使用 SSH）：上传自身二进制（`os.Executable()`，可配 `binary_path` 指定交叉编译产物）到 `/tmp/.wdp-agent-<rand>`；经 SSH 写入随机 32B token 到 `--token-file`（agent 读取后自删，避免 ps 泄漏）
  2. **启动真端口**：`nohup <bin> agent --listen 0.0.0.0:<port> --token-file <f> &`；端口默认 **7602**（host 键 `agent_port` 可指定；未显式指定且占用时自动换随机高位端口重试）
  3. **直连执行**：自举成功后控制端直连 `http://host:port`（HTTP+token，连接池复用，与常驻 agent 同等吞吐），**SSH 连接随即释放**
  4. **自清理**：agent 增加 `--cleanup-on-shutdown`（收到 /shutdown 时 `rm` 自身 os.Args[0] 再退出）；Manager.CloseAll 触发；`keep_agent: true` 可保留调试
- 失败回退：agent 启动超时/不可达 → 回退纯 SSH 执行并告警
- 实现于 internal/connection/pushagent（组合 sshconn 做自举 + agentconn 做执行）

## Phase 6：chart 增强
- **check 模式**（`--check`）：RunContext 增加 `CheckMode`；copy/template（远端 checksum 只读对比）、file（状态探测）、package/service（当前态探测）返回真实 changed 预估；shell 返回 changed=true+标注"check: 将执行"
- **block/rescue/always**：Task 增加 Block/Rescue/Always 任务组字段（playbook 解析 `block:`/`rescue:`/`always:` 键），组内失败转 rescue、always 恒执行，支持嵌套与组级 when/become
- **until 轮询**：task 属性 `until: '{{ if eq .h.rc 0 }}ok{{ end }}'`；有 until 时 retries=总尝试上限、delay=间隔，每次重试后用最新 register 值渲染判断；耗尽才计失败（与无 until 的纯失败重试语义区分）
- **部署记录**：run 结束写 `~/.wdp/releases/<chart>-<ts>.json`（chart 版本+values 快照+统计）；`wdp release list/show <id> [--values]`（--values 输出快照可直接 `-f` 重放）
